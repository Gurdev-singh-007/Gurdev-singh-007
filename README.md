### 🕹️ The Origin: PlayStation Arcade Roots
I grew up inside a family-run PlayStation arcade. Before writing code, I was opening broken PS1, PS2, and PS3 controllers, diagnosing hardware failures, and fixing machines. 

I didn't just play games—I completed nearly every major PS2/PS3 title on **Hard Difficulty** (Story Mode). Spending thousands of hours inside these games gave me a deep, natural intuition for how movement, hitboxes, input response, and combat state machines ought to *feel*.

### 🛠️ Current Focus & Mission: C++ From The Ground Up

My core focus right now is mastering **C++ from absolute fundamentals to low-level systems**:

- ⚙️ **C++ Core Foundation:** Deep-diving into pointers, references, dynamic memory management (`heap` vs `stack`), and standard templates (STL).
- 🧠 **Data Structures for Games:** Understanding custom vectors, linked memory structures, and cache line performance.
- 🔄 **Engine Mechanics Study:** Writing pure C++ prototypes for Finite State Machines (FSMs) and character input buffers.
- 🎯 **Unreal Engine 5 Frameworks:** Preparing to translate raw C++ logic into UE5 Gameplay Frameworks.
